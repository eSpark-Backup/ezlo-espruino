Espruino is an open-source JavaScript interpreter specifically designed for microcontrollers. It enables the development of embedded systems using JavaScript, allowing for easy programming and interaction with hardware components. For the ESP32, Espruino offers a platform to write JavaScript code that runs directly on the microcontroller, enabling rapid prototyping and development of IoT (Internet of Things) projects.

With Espruino on ESP32, you can leverage the power of JavaScript to control GPIO pins, interact with sensors, manage networking protocols like Wi-Fi, and build various IoT applications without the need for traditional embedded programming languages. It simplifies the development process by providing a familiar language for web developers to work with hardware, making it accessible for a broader range of enthusiasts and professionals alike.

Espruino's ease of use, compatibility with various microcontrollers, and its ability to execute JavaScript directly on hardware make it a popular choice for IoT and embedded systems development, especially for those with a background in web development.

/******************************************************************/
			  Espruino Setup:
/******************************************************************/
1. Open Espruino WebIDE using above Link
2. Click on Gear icon to open settings -> COMMUNICATIONS -> Change Baudrate to 115200 -> click on Cross to close menu
3. Connect Esp32 to System -> Click on Web Serial and choose your COM port, you can verify yours using Device Manager -> Ports
4. Once connected you can now program using terminal line by line or upload script to Esp32

/******************************************************************/
			 LED Toggle example
/******************************************************************/
Summary:  This example toggles the LED on GPIO 2 at 500ms
var on = false;
function toggle() {
 on = !on;
 digitalWrite(LED1, on);
}

toggle();
var i = setInterval(toggle, 500);

Note:
reset(), when controller reaches to this point it will clear previously uploaded script 

/******************************************************************/
			 WiFi connectivity example
/******************************************************************/

Summary: This example connects to WiFi network provided, but to make it work we need to Flash upload it because WiFi functionality requires reboot
var ssid = 'YOUR_SSID';
var password = 'YOUR_SSID_PASSWORD';

var wifi = require('Wifi');
wifi.connect(ssid, {password: password}, function() {
    console.log('Connected to Wifi.  IP address is:', wifi.getIP().ip);
    wifi.save(); // Next reboot will auto-connect
});

/******************************************************************/
			 GPIO read example
/******************************************************************/

Summary: this example reads GPIO 14 status using GPIO 25 for this to work you need to connect GPIO 14 with GPIO 25 using jumper, it will result as below
Before: false 
After: true

D14.mode('output');
D25.mode('input');
console.log('Before: ', D25.read());
D14.set();                  // Set the D14 pin to output a HIGH value.
console.log('After: ', D25.read());

/******************************************************************/
			 Serial2 write example
/******************************************************************/
Summary: this example prints at UART2 for this use UART to ttl to connect with serial terminal
This will output:
	Hello UART
Serial2.setup(9600, { tx: D4, rx: D15 });

    console.log('Serial2: ', data);
});
Serial2.print('Hello UART');
